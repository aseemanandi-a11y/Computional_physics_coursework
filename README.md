# Computional_physics_coursework
codes from my 5th semester computational physics course
This repository contains basic codes in the topics listed below done as part of the computational physics course - 
- Numerical Differentiation
- Numerical Integration
- Random number generators and random walk
- Differential equations - Euler and Runge Kutta methods
- Introduction to solving Partial Differential Equations
- Finding roots of polynomials and transcendental equations
The above list is incomplete as the course is still ongoing

## Main Project
The repository also contains a larger project from the same course Based on the 1-D Navier-Stokes equations

##  Repository Structure & Custom Library
- Custom Physics Library: This library contains all the custom functions created and used as part of this course
- Class Scripts: Individual scripts are organized chronologically based on lab sessions. 

##  Languages & Libraries Used
- Python 3
- math (standard library)
- NumPy (for numerical methods, matrix operations, and differential equations)
- Matplotlib (for plotting and data visualization)
